# Yatra – India Travel Agent

## Project Overview

Yatra is an AI-powered Travel Planner Agent designed to help users plan trips across India through a conversational interface.

It uses IBM Granite to understand user requirements and provide personalized travel recommendations, itineraries, budget guidance, transportation suggestions, food recommendations, and cultural information.

## Features

- Personalized travel planning
- Day-wise itinerary generation
- Destination recommendations
- Budget planning
- Transportation guidance
- Food and cultural recommendations
- Conversational travel assistance
- IBM Granite AI integration
